# C FTP Server & Client Implementation

## 📌 프로젝트 소개
시스템 프로그래밍 과제(#3-2)로 진행된 C언어 기반의 다중 접속 FTP(File Transfer Protocol) 서버 및 클라이언트 구현 프로젝트입니다. Ubuntu 20.04 환경에서 동작하며, 사용자 인증 및 IP 접근 제어 기능을 포함한 소켓 프로그래밍을 통해 클라이언트-서버 간의 파일 송수신과 디렉터리 제어 명령을 처리합니다.

## 📂 파일 구성 및 역할

| 파일명 | 역할 및 설명 |
| :--- | :--- |
| `Makefile` | `make` 명령어를 통해 `cli`, `srv` 실행 파일을 일괄 컴파일합니다. `make clean`으로 빌드 산출물을 삭제할 수 있습니다. |
| `access.txt` | 서버 접속을 허용할 IP 주소 목록을 관리합니다. (예: `128.134.64.*` 와일드카드 지원) |
| `passwd` | 사용자 인증에 사용되는 계정 정보 파일입니다. `/etc/passwd`와 동일한 포맷을 사용하며, 두 번째 필드를 비밀번호로 사용합니다. (예: `test1:12:0:0:SPLab1:/home/1:sh1`) |
| `srv.c` | 서버 측 구현 소스 코드로, 클라이언트의 접속 수락, IP/계정 인증, 제어 명령 처리 및 파일 송수신을 담당합니다. |
| `cli.c` | 클라이언트 측 구현 소스 코드로, 서버 접속, 사용자 명령 입력 처리, 서버와의 통신 및 제어를 담당합니다. |

## 🚀 빌드 및 실행 방법

### 환경
* OS: Ubuntu 20.04
* 컴파일러: gcc

### 빌드 (컴파일)
```bash
make

실행
서버 실행
./srv <포트번호>

클라이언트 실행
./cli <서버IP> <포트번호>

아키텍처 및 연결 방식
본 시스템은 두 가지 형태의 연결을 사용하여 통신을 제어합니다.
제어 연결 (Control Connection): 사용자 명령과 서버의 응답 코드(예: 200, 220, 530 등)가 오가는 TCP 연결입니다.
데이터 연결 (Data Connection): 액티브 모드(PORT 명령어 사용)로 생성되며, ls 명령에 의한 파일 목록이나 실제 파일 데이터(업로드/다운로드)가 오가는 연결입니다.
주요 기능 구현 상세
1. 서버 (Server - srv.c)
접속 수락 및 분기 (main)
socket, bind, listen을 호출하여 TCP 리스닝 소켓을 생성합니다.
무한 루프 내에서 accept로 접속을 받고, 자식 프로세스를 fork()하여 다중 클라이언트 요청을 병렬로 처리합니다. (부모는 wait으로 회수)
IP 기반 접근 제어 (checkAccess)
클라이언트 IP를 4옥텟으로 나누어 access.txt의 목록과 비교합니다.
인가되지 않은 IP일 경우 431 에러 코드를 반환하고 세션을 즉시 종료합니다.
사용자 로그인 인증 (log_auth & user_match)
클라이언트가 전송한 USER, PASS 명령의 인자를 파싱하여 passwd 파일 내의 정보와 비교(fgetpwent 사용)합니다.
상태에 따라 331(비밀번호 요청), 230(로그인 성공), 430(계정 불일치), 530(3회 실패 시 종료) 등의 응답 코드를 전송합니다.
명령 처리 루프 (handle_client & cmd_process)
클라이언트의 명령에 따라 분기하여 작업을 수행합니다.
PORT: 파싱한 클라이언트 IP와 포트(p1*256+p2) 정보로 서버가 connect()하여 액티브 모드 데이터 연결을 맺습니다.
NLST/LIST: scandir, lstat 등을 활용하여 파일 목록(옵션 지원)과 ls -l 형태의 속성 정보를 생성한 뒤 데이터 소켓으로 전송합니다.
RETR/STOR: 전역 변수 is_binary 값(TYPE I/A)에 따라 바이너리(rb/wb) 또는 텍스트(r/w) 모드로 파일을 열고, 1KB 단위로 읽고 쓰며 바이트 수를 출력합니다.
기타 디렉터리 제어: PWD(getcwd), CWD/CDUP(chdir), MKD(mkdir), DELE(unlink), RMD(rmdir), RNFR/RNTO(rename) 기능을 각각의 C 표준 라이브러리 함수로 구현하여 제어 소켓으로 응답 코드를 반환합니다.
2. 클라이언트 (Client - cli.c)
초기 접속 및 로그인 (log_in)
실행 시 입력된 IP와 포트로 서버에 연결한 후 응답 코드를 대기합니다.
서버의 응답 상태에 따라 프롬프트에서 사용자 이름과 비밀번호를 입력받아 인증 과정을 수행합니다.
사용자 명령 변환 (conv_cmd)
ftp> 프롬프트에서 입력받은 직관적인 리눅스 스타일의 명령어를 규격화된 FTP 프로토콜 명령어로 매핑하여 서버에 전송합니다.
(예: ls -> NLST, cd -> CWD, get -> RETR, bin -> TYPE I 등)
액티브 데이터 연결 구성 (make_data_connection)
10001~30000 범위에서 난수로 임의의 포트를 선택하고 해당 포트로 데이터 소켓을 bind, listen 합니다.
IP와 계산된 포트 쌍(p1, p2)을 조합하여 PORT 명령을 서버로 전송하고 서버의 접속(accept)을 대기합니다.
파일 전송 (get, put)
데이터 연결이 수립되면 서버의 RETR, STOR 명령과 호흡을 맞춰 파일을 송수신하고 전송된 데이터 바이트 수를 화면에 출력합니다.
